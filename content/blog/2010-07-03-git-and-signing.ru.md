Сейчас я активно использую git для управления конфигурациями и захотел подписывать свои объекты. Полных руководств на эту тему я не нашёл, поэтому вот список инструкций, к которому я в итоге пришёл:

- Если у вас уже есть ключ, которым вы что-то подписываете (почту, код, что угодно), можно сразу перейти к пункту 4. Если нет, решите, какое имя, email и парольную фразу вы будете использовать для подписи кода.
- Создайте пару ключей на основе выбранных имени, email и парольной фразы. Это делается командой `gpg2 --gen-key`. Программа интерактивная и очень простая в использовании. В Ubuntu и Debian она входит в пакет `gnupg2`. Ключи создаются в `~/.gnupg`. Если хотите убедиться, что всё прошло хорошо, можно вывести список всех ключей командой `gpg2 --list-public-keys`.
- Настройте git на использование вашего email. Обычно для этого нужно отредактировать файл конфигурации git `~/.gitconfig` и задать параметр `email` в разделе `user`, указав в нём свой email.
- Подписывайте изменение, когда делаете коммит или ставите тег. Для коммита используйте "git -s commit". Для тега — "git tag -s -m 'commit message' [tagname]".
