Вы скачали фильм и подходящий файл субтитров `.srt`, и хотите, чтобы они путешествовали вместе, — чтобы любой проигрыватель показывал субтитры без указаний, где их искать. Сделать это можно двумя способами, и разница между ними важна.

## Мягкие субтитры: оставить их дорожкой

Мягкие субтитры — это отдельная дорожка внутри контейнера, рядом с видео и звуком. Проигрыватель может включать и выключать её, а видео не затрагивается, поэтому нет потери качества и операция занимает секунду: ничего не перекодируется.

С `mkvmerge` из пакета mkvtoolnix, в файл Matroska:

```bash
mkvmerge -o movie.mkv movie.mp4 --language 0:eng subtitles.srt
```

С `ffmpeg`, копируя все потоки и добавляя дорожку субтитров:

```bash
ffmpeg -i movie.mp4 -i subtitles.srt -c copy -c:s mov_text movie_out.mp4
```

Главное здесь — `-c copy`: он говорит копировать потоки как есть, а не перекодировать. Для вывода в MKV можно убрать `mov_text` и оставить SRT как SRT; `mov_text` — это кодек субтитров, которого требует MP4.

Мягкие субтитры — правильный выбор по умолчанию. Они без потерь, обратимы и оставляют выбор зрителю.

## Жёсткие субтитры: вжечь их

Иногда нужно, чтобы субтитры были нарисованы прямо в изображении, потому что целевое устройство не умеет показывать дорожку субтитров или потому что вы загружаете видео туда, где их игнорируют. Это называется вжиганием, и оно перекодирует видео, поэтому медленнее и стоит немного качества:

```bash
ffmpeg -i movie.mp4 -vf subtitles=subtitles.srt movie_hardsubbed.mp4
```

Вжжённые субтитры уже нельзя выключить. Делайте это, только когда приходится.

## Пакетное сопоставление файлов

Если у вас папка с видео и папка с субтитрами, названными одинаково с точностью до расширения, вы не хотите набирать команду для каждого файла. Вот небольшой скрипт на Python, который сопоставляет их по имени без расширения и объединяет каждую пару:

```python
#!/usr/bin/env python3
import subprocess
from pathlib import Path

for video in Path(".").glob("*.mp4"):
    srt = video.with_suffix(".srt")
    if not srt.exists():
        print(f"no subtitle for {video.name}, skipping")
        continue
    out = video.with_name(video.stem + ".subbed.mkv")
    subprocess.run(
        ["mkvmerge", "-o", str(out), str(video),
         "--language", "0:eng", str(srt)],
        check=True,
    )
    print(f"{video.name} + {srt.name} -> {out.name}")
```

Он находит по шаблону каждый `.mp4`, ищет `.srt` с тем же именем, пропускает файлы без пары вместо того, чтобы падать, и записывает новый `.subbed.mkv`, так что оригиналы остаются нетронутыми. Подправьте шаблон и тег языка под себя.

## Что выбрать

Берите мягкие субтитры, если только что-то вас не вынуждает. Они ничего не стоят, их можно отменить, и они оставляют выбор тому, кто смотрит. Вжигайте только для устройства или сервиса, не умеющего читать дорожку субтитров, и храните копию с мягкими субтитрами как основную.
