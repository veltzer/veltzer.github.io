LilyPond היא לתווים מה ש-LaTeX הוא למסמכים: מתארים את המוזיקה בקובץ טקסט ומהדר מייצר חריטה יפהפייה.
המחיר זהה למחיר של LaTeX. התחביר דחוס, יש ממנו הרבה, ואני שוכח את החלקים שאני משתמש בהם לעיתים
רחוקות. זהו העמוד שהייתי רוצה שיהיה לי, קצר בכוונה: המבנים שמכסים כמעט כל יצירה שאני מתווה, ולא
דבר מעבר להם.

**כל מה שלמטה נכנס לקובץ טקסט רגיל שמסתיים ב-`.ly`, ו-`lilypond file.ly` הופך אותו ל-`file.pdf`.**

## השלד

```lilypond
\version "2.18.2"

\header {
  title = "Example"
  composer = "Anonymous"
}

\relative c' {
  \clef treble
  \key g \major
  \time 3/4
  d4 g b | a2. | \bar "|."
}
```

שורת ה-`\version` היא חובה ומאפשרת לכלי `convert-ly` לעדכן את הקובץ שלכם כשהתחביר משתנה. הסוגריים
המסולסלים אחרי `\relative` מחזיקים את המוזיקה.

## גבהים וסימני היתק

תווים הם אותיות קטנות `c d e f g a b`. דיאזים ובמולים הם סיומות: `cis` הוא דו דיאז, `bes` הוא סי
במול, `cisis` ו-`beses` הם דיאז כפול ובמול כפול. `r` היא הפסקה, `s` הוא מרווח שקט שתופס זמן בלי להדפיס
דבר.

אוקטבות מסומנות ב-`'` (למעלה) וב-`,` (למטה). במצב מוחלט `c'` הוא דו האמצעי, `c''` האוקטבה מעליו, `c`
האוקטבה מתחתיו.

## מצב יחסי

כמעט כולם כותבים במצב יחסי, מפני שהוא מסלק את רוב סימני האוקטבה. בתוך `\relative c' { ... }` כל תו
ממוקם באוקטבה שמביאה אותו קרוב ככל האפשר לתו הקודם, בתוך קווארטה. כשהמרווח הוא קווינטה או יותר
מוסיפים `'` או `,` כדי לומר לאיזה כיוון לקפוץ:

```lilypond
\relative c' { c d e f g a b c }      % one rising scale, no marks needed
\relative c' { c g' c, }              % g a fifth up, then c a fourth down
```

הארגומנט אחרי `\relative` קובע את ההתייחסות לתו הראשון בלבד.

## משכים

מספר אחרי התו הוא המשך: `c1` שלם, `c2` חצי, `c4` רבע, `c8` שמינית, `c16` שש-עשרית. נקודה מאריכה
במחצית: `c4.`. משך נדבק עד שכותבים חדש, אז `c4 d e f` הם ארבעה רבעים.

קשתות הארכה משתמשות ב-`~`, קבוצות לא סדירות ב-`\tuplet`:

```lilypond
c4~ c8 d8 | \tuplet 3/2 { e8 f g } a4
```

בדיקות תיבה עם `|` הן אופציונליות אבל תופסות שגיאות ספירה: LilyPond מזהירה כשקו תיבה נופל במקום
הלא נכון.

## סולם, משקל, מפתח

```lilypond
\key d \minor
\time 6/8
\clef bass
```

מפתחות: `treble`, `bass`, `alto`, `tenor`, `percussion`. סימן סולם הוא `\key` ואחריו גובה ו-`\major`
או `\minor`. שינוי של כל אחד מאלה באמצע היצירה הוא פשוט לכתוב אותו שוב במקום שהשינוי קורה.

## אקורדים

תווים בו-זמניים נכנסים לסוגריים משולשים, עם המשך אחרי הסוגר הסוגר:

```lilypond
<c e g>4 <d f a>4 <e g c'>2
```

לסימני אקורדים מעל החמשה, השתמשו במצב אקורדים, שבו אות וסיומת מציינות את האקורד:

```lilypond
\chords { c1 f2 g2:7 a1:m }
```

## דינמיקה, ארטיקולציה, טמפו

דינמיקה נצמדת לתו עם לוכסן אחורי: `c4\p d\mf e\f f\ff`. קרשנדו ודימינואנדו הם `\<` ו-`\>`,
ומסתיימים ב-`\!`:

```lilypond
c4\< d e f\! g4\> f e d\!
```

סימני ארטיקולציה הם סיומות: `c4-.` סטקטו, `c4->` אקצנט, `c4-^` מרקטו, `c4\fermata`. קשתות הן
סוגריים סביב המשפט: `c4( d e f)`. קשתות מבע משתמשות ב-`\(` וב-`\)`.

הטמפו הולך בראש המוזיקה:

```lilypond
\tempo "Allegro" 4 = 120
```

## מילים

כתבו את הלחן, ואז צרפו מילים בהברה אחת לכל תו; מקפים מחברים הברות של מילה ו-`__` מאריך הברה על פני
כמה תווים:

```lilypond
\relative c' {
  \time 4/4
  c4 d e f | g2 g
}
\addlyrics {
  Twin -- kle twin -- kle lit -- tle star
}
```

`\addlyrics` בא אחרי ביטוי המוזיקה שהוא שייך לו. ליותר מבית אחד, חזרו עליו.

## כמה קולות וחמשות

שני קולות עצמאיים על חמשה אחת:

```lilypond
\relative c'' {
  << { e4 f g a } \\ { c4 d e f } >>
}
```

ה-`<<` וה-`>>` אומרים בו-זמני, וה-`\\` מפצל את התוכן לקולות עם גבעולים שמצביעים לכיוונים מנוגדים.

כמה חמשות הן `\new StaffGroup` או, לפסנתר, `\new PianoStaff`, שכל אחד מהם מכיל בלוקים של
`\new Staff`:

```lilypond
\new PianoStaff <<
  \new Staff = "right" \relative c'' { c4 d e f | g1 }
  \new Staff = "left"  \relative c  { \clef bass c4 e g e | c1 }
>>
```

## חזרות

```lilypond
\repeat volta 2 { c4 d e f }
\alternative { { g2 g } { g2 c } }
```

`volta` מדפיס קווי חזרה ואת הסיומות החלופיות; `\repeat unfold 2 { ... }` כותב את המוזיקה פעמיים
במקום זאת.

## הידור

```bash
lilypond piece.ly           # produces piece.pdf and piece.midi if \midi is present
lilypond --png piece.ly     # a PNG instead
convert-ly -e piece.ly      # update the file to the installed version's syntax
```

הוסיפו בלוק `\layout { }` לחריטה ובלוק `\midi { }` לצליל בתוך `\score { ... }` כשאתם רוצים את שניהם
מקובץ אחד.

## למה גיליון כה קצר

מפני שהמדריך מצוין וענקי, ואני לא רוצה את המדריך. אני רוצה את עשרים הדברים שמכסים המנון, שיר עם,
תרגיל דו-קולי וגיליון ליווי. זה מה שלמעלה. **כשיצירה צריכה משהו שאינו בעמוד הזה, זה האות לפתוח את
המדריך, ולא לפני כן.**
