אני מוצא את עצמי לא פעם צריך להכניס נתונים ידנית למסד נתונים של MySQL באמצעות עורך מסדי נתונים
כלשהו. בעורך כזה אתם מוצאים את עצמכם מקלידים ערכים ידנית לתאים בטבלה, וברובם לא מאפשרים לכם
להזין ביטוי SQL (ה־MySQL Query Browser הוא דוגמה מובהקת). במקרה כזה אני צריך דרך כלשהי לייצר
במהירות את התאריך והשעה הנוכחיים בפורמט של MySQL משורת הפקודה. בדרך כלל אשתמש ב:

`alias date_mysql="date +'%F %T'"`
