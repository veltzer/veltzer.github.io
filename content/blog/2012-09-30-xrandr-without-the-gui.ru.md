В каждой среде рабочего стола есть диалог настроек дисплеев, и у каждого из них один и тот же недостаток: он забывает. Вы подключаете ноутбук к проектору, диалог угадывает неправильно, вы исправляете вручную, отключаете, а на следующей неделе делаете всё заново. Нужная вам раскладка каждый раз одна и та же. Инструмент, который её устанавливает, должен быть командой, а не беседой.

**Всё, что делает диалог, `xrandr` делает из оболочки, а команду можно сохранить.** Вот его ровно столько, сколько нужно, чтобы перестать трогать диалог.

## Посмотрите, что у вас есть

```bash
xrandr --query
```

Вывод перечисляет каждый выход, о котором знает видеокарта, подключено ли к нему что-нибудь, и режимы, которые поддерживает каждый подключённый экран, — текущий отмечен звёздочкой, предпочтительный — плюсом. Типичный ноутбук показывает что-то вроде:

```text
LVDS1 connected 1366x768+0+0 (normal left inverted right x axis y axis) 344mm x 194mm
   1366x768       60.0*+
   1024x768       60.0
VGA1 connected 1920x1080+1366+0 (normal left inverted right x axis y axis) 510mm x 287mm
   1920x1080      60.0*+
   1280x1024      60.0
HDMI1 disconnected (normal left inverted right x axis y axis)
```

Имена слева (`LVDS1`, `VGA1`, `HDMI1`) — это то, на что ссылаются все остальные команды. Для данной машины они стабильны, что и делает возможным сохранённый скрипт.

## Установите режим

Чтобы задать одному выходу конкретное разрешение:

```bash
xrandr --output VGA1 --mode 1920x1080
```

Чтобы он сам выбрал режим, который монитор сообщает как предпочтительный, — это почти всегда правильно:

```bash
xrandr --output VGA1 --auto
```

Чтобы выключить выход — это то, что нужно для панели ноутбука, когда крышка закрыта:

```bash
xrandr --output LVDS1 --off
```

## Расположите их

Положение задаётся относительно другого выхода:

```bash
xrandr --output VGA1 --auto --right-of LVDS1
```

Альтернативы — `--left-of`, `--above` и `--below`. Для презентации обычно нужно, чтобы проектор вместо этого дублировал ноутбук:

```bash
xrandr --output VGA1 --auto --same-as LVDS1
```

Дублирование работает чисто, только когда оба экрана работают в одном режиме, так что, возможно, стоит принудительно задать общий через `--mode` на обоих. А когда монитор установлен не той стороной:

```bash
xrandr --output VGA1 --rotate left
```

Всё это объединяется в одну команду, и одна команда лучше нескольких, потому что X-сервер перенастраивается один раз, а не мерцает через промежуточные состояния:

```bash
xrandr --output LVDS1 --auto --output VGA1 --auto --right-of LVDS1 --output HDMI1 --off
```

## Сохраните раскладки, которыми пользуетесь

Теперь — смысл всего упражнения. Положите раскладки, которыми вы реально пользуетесь, в скрипт, по одной функции на ситуацию:

```bash
#!/bin/bash
# screens.sh - set a known display layout

set -e

home() {
	xrandr --output LVDS1 --auto \
	       --output VGA1 --auto --right-of LVDS1 \
	       --output HDMI1 --off
}

laptop() {
	xrandr --output LVDS1 --auto \
	       --output VGA1 --off \
	       --output HDMI1 --off
}

projector() {
	xrandr --output LVDS1 --mode 1024x768 \
	       --output VGA1 --mode 1024x768 --same-as LVDS1
}

case "$1" in
	home|laptop|projector) "$1" ;;
	*) echo "usage: $0 home|laptop|projector" >&2; exit 1 ;;
esac
```

Сделайте его исполняемым и положите в свой путь. С этого момента весь ритуал сводится к:

```bash
screens.sh projector
```

Привяжите частые случаи к клавишам в оконном менеджере — и терминал вам тоже не понадобится.

## Почему бы не доверить это рабочему столу

Потому что он не может знать, чего вы хотите. Среда рабочего стола видит новый монитор и вынуждена гадать: дублировать или расширять, с какой стороны, в каком разрешении. Её догадка — это значение по умолчанию, а значения по умолчанию — для тех, кто ещё не решил. Вы решили. У вас три-четыре раскладки, и вы знаете, какая нужна, взглянув на комнату.

**Решение, которое вы уже приняли, должно быть одной командой, а команду можно назвать, сохранить, поставить под контроль версий и привязать к клавише.** Диалог не предлагает ничего из этого. Он каждый раз предлагает новую догадку и просит исправить её мышью.

Скрипт выше — около двадцати строк. Он сэкономил мне больше минут, чем что-либо ещё такого же размера.
