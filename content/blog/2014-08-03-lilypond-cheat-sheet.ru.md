LilyPond для нотной записи — то же, что LaTeX для документов: вы описываете музыку в текстовом файле, а компилятор выдаёт красивую гравировку. Цена та же, что и с LaTeX. Синтаксис компактен, его много, и то, чем я пользуюсь редко, я забываю. Это та страница, которая мне была нужна, нарочно короткая: конструкции, которых хватает почти для любой пьесы, что я набираю, и ничего больше.

**Всё, что ниже, пишется в обычном текстовом файле с расширением `.ly`, а `lilypond file.ly` превращает его в `file.pdf`.**

## Каркас

```lilypond
\version "2.18.2"

\header {
  title = "Example"
  composer = "Anonymous"
}

\relative c' {
  \clef treble
  \key g \major
  \time 3/4
  d4 g b | a2. | \bar "|."
}
```

Строка `\version` обязательна и позволяет утилите `convert-ly` обновить ваш файл, когда синтаксис меняется. В фигурных скобках после `\relative` находится сама музыка.

## Высоты и знаки альтерации

Ноты — строчные буквы `c d e f g a b`. Диезы и бемоли — суффиксы: `cis` — до-диез, `bes` — си-бемоль, `cisis` и `beses` — дубль-диез и дубль-бемоль. `r` — пауза, `s` — невидимый заполнитель, который занимает время, ничего не печатая.

Октавы обозначаются `'` (вверх) и `,` (вниз). В абсолютном режиме `c'` — до первой октавы, `c''` — октавой выше, `c` — октавой ниже.

## Относительный режим

Почти все пишут в относительном режиме, потому что он избавляет от большинства октавных знаков. Внутри `\relative c' { ... }` каждая нота помещается в ту октаву, где она ближе всего к предыдущей, в пределах кварты. Когда интервал — квинта или больше, вы добавляете `'` или `,`, чтобы указать, куда прыгать:

```lilypond
\relative c' { c d e f g a b c }      % one rising scale, no marks needed
\relative c' { c g' c, }              % g a fifth up, then c a fourth down
```

Аргумент после `\relative` задаёт точку отсчёта только для первой ноты.

## Длительности

Число после ноты — её длительность: `c1` целая, `c2` половинная, `c4` четвертная, `c8` восьмая, `c16` шестнадцатая. Точка удлиняет на половину: `c4.`. Длительность сохраняется, пока вы не напишете новую, так что `c4 d e f` — это четыре четверти.

Лиги-связки пишутся через `~`, дольки (триоли и т. п.) — через `\tuplet`:

```lilypond
c4~ c8 d8 | \tuplet 3/2 { e8 f g } a4
```

Проверки тактов с помощью `|` необязательны, но ловят ошибки счёта: LilyPond предупреждает, когда тактовая черта приходится не на то место.

## Тональность, размер, ключ

```lilypond
\key d \minor
\time 6/8
\clef bass
```

Ключи: `treble`, `bass`, `alto`, `tenor`, `percussion`. Тональность — это `\key`, за которым следуют высота и `\major` или `\minor`. Чтобы сменить что-либо из этого посреди пьесы, достаточно написать это снова в месте смены.

## Аккорды

Одновременно звучащие ноты пишутся в угловых скобках, а длительность — после закрывающей скобки:

```lilypond
<c e g>4 <d f a>4 <e g c'>2
```

Для буквенных обозначений аккордов над нотоносцем используется аккордовый режим, где буква и суффикс называют аккорд:

```lilypond
\chords { c1 f2 g2:7 a1:m }
```

## Динамика, артикуляция, темп

Динамика присоединяется к ноте через обратную косую черту: `c4\p d\mf e\f f\ff`. Крещендо и диминуэндо — `\<` и `\>`, завершаются `\!`:

```lilypond
c4\< d e f\! g4\> f e d\!
```

Знаки артикуляции — суффиксы: `c4-.` стаккато, `c4->` акцент, `c4-^` маркато, `c4\fermata`. Лиги — это круглые скобки вокруг фразы: `c4( d e f)`. Фразировочные лиги пишутся через `\(` и `\)`.

Темп указывается в начале музыки:

```lilypond
\tempo "Allegro" 4 = 120
```

## Текст песни

Напишите мелодию, затем присоедините слова по одному слогу на ноту; дефисы соединяют слоги одного слова, а `__` растягивает слог на несколько нот:

```lilypond
\relative c' {
  \time 4/4
  c4 d e f | g2 g
}
\addlyrics {
  Twin -- kle twin -- kle lit -- tle star
}
```

`\addlyrics` следует за тем музыкальным выражением, к которому относится. Для нескольких куплетов повторите его.

## Несколько голосов и нотоносцев

Два независимых голоса на одном нотоносце:

```lilypond
\relative c'' {
  << { e4 f g a } \\ { c4 d e f } >>
}
```

`<<` и `>>` означают «одновременно», а `\\` делит содержимое на голоса со штилями, направленными в противоположные стороны.

Несколько нотоносцев — это `\new StaffGroup` или, для фортепиано, `\new PianoStaff`, каждый из которых содержит блоки `\new Staff`:

```lilypond
\new PianoStaff <<
  \new Staff = "right" \relative c'' { c4 d e f | g1 }
  \new Staff = "left"  \relative c  { \clef bass c4 e g e | c1 }
>>
```

## Повторы

```lilypond
\repeat volta 2 { c4 d e f }
\alternative { { g2 g } { g2 c } }
```

`volta` печатает знаки повторения и вольты; `\repeat unfold 2 { ... }` вместо этого выписывает музыку дважды.

## Компиляция

```bash
lilypond piece.ly           # produces piece.pdf and piece.midi if \midi is present
lilypond --png piece.ly     # a PNG instead
convert-ly -e piece.ly      # update the file to the installed version's syntax
```

Добавьте блок `\layout { }` для гравировки и блок `\midi { }` для звука внутри `\score { ... }`, если хотите получить и то, и другое из одного файла.

## Почему шпаргалка такая короткая

Потому что руководство превосходное и огромное, а руководство мне не нужно. Мне нужны те двадцать вещей, которых хватает на гимн, народную мелодию, двухголосное упражнение и лид-шит. Это и есть то, что выше. **Когда пьесе нужно что-то, чего нет на этой странице, это сигнал открыть руководство — и не раньше.**
