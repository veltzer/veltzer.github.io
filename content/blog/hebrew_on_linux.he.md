עברית בלינוקס עובדת, ועובדת כבר שנים, אבל החלקים חיים במקומות שונים ואיש אינו מוסר לכם את הרשימה.
זו הרשימה שהייתי רוצה שימסרו לי: המקלדת, הגופנים, טקסט מימין לשמאל במקומות שמעולם לא תוכננו לו,
ובדיקת איות.

## המקלדת

אתם רוצים שתי פריסות, מקש להחלפה ביניהן, ומחוון כדי שתדעו באיזו מהן אתם. בכל שולחן עבודה מודרני זה
חלון הגדרות, אבל זו גם פקודה אחת, וזה שימושי במנהל חלונות שאין לו חלון כזה:

```bash
setxkbmap -layout "us,il" -option "grp:alt_shift_toggle,grp_led:scroll"
```

Alt+Shift מחליף את הפריסה ונורת Scroll Lock אומרת לכם כשאתם בעברית. שימו זאת בקובץ ההפעלה של X
וזה שורד התחברויות. אם אתם מעדיפים מקש החלפה אחר, `man xkeyboard-config` מפרט את אפשרויות ה-`grp:`;
הגרסה של Caps Lock פופולרית בקרב אנשים שלעולם אינם משתמשים ב-Caps Lock.

הפריסה הישראלית התקנית שמה את האותיות במקום שבו שמה אותן מכונת כתיבה עברית. לפריסת `il` יש גם
גרסת `phonetic` לאנשים שמעולם לא למדו את הסידור הזה ומעדיפים אלף מתחת ל-A.

## גופנים

גופני ברירת המחדל ברוב ההפצות כוללים את DejaVu, שיש בו עברית, ולכן טקסט מוצג. הוא אינו מוצג יפה.
לכל דבר שתקראו לאורך זמן, התקינו את אוסף Culmus, שהוא משפחת הגופנים העבריים החופשית שנוצרה בדיוק
לזה:

```bash
sudo apt-get install culmus
```

אתם מקבלים את דוד, פרנק-ריהל, מרים, נחלאלי ואחרים, שמכסים את מקרי הסריף, הסאנס והרוחב הקבוע. ואז
הריצו `fc-cache -f` ובחרו בהם בכל יישום שאתם משתמשים בו. פרנק-ריהל הוא זה שנראה כמו ספר מודפס.

## מימין לשמאל במסופים

הנה החלק שהוא באמת מסורבל. מסוף הוא רשת של תאים שמתמלאים משמאל לימין, ואין לו שום מושג של טקסט
דו-כיווני. עברית יוצאת הפוכה: האותיות נכונות אבל הסדר הפוך, ושורות מעורבות של עברית ואנגלית
מתערבבות.

התיקון הוא מסנן שמחיל את האלגוריתם הדו-כיווני של יוניקוד על כל שורה ופולט את התווים בסדר חזותי, כך
שתצוגה טיפשה משמאל לימין מציגה אותם נכון. הכלי הוא `fribidi`:

```bash
sudo apt-get install fribidi
cat hebrew_file.txt | fribidi
```

לישיבה שלמה אפשר לעטוף דברים שאתם קוראים לעיתים קרובות:

```bash
alias hcat='fribidi'
alias hless='fribidi | less'
```

זה טריק תצוגה, לא תיקון. אם תעתיקו טקסט מהמסוף הוא יהיה בסדר חזותי ושגוי. לעריכת עברית השתמשו
בעורך שמבין דו-כיווניות: Vim עם `set rightleft` לקבצי עברית טהורה, Emacs עם תמיכת הדו-כיווניות שלו,
או כל עורך גרפי, שכולם עושים זאת כראוי. **המסוף הוא להסתכלות על עברית; עשו את הכתיבה במקום שיודע
לאיזה כיוון הוא הולך.**

## בדיקת איות

בודק האיות העברי הוא Hspell, מנתח מורפולוגי שבאמת מבין את השפה ולא מתאים לרשימת מילים. הוא מתחבר
לכל מה שמדבר בממשק Hunspell:

```bash
sudo apt-get install hspell hunspell-he
```

אחרי זה LibreOffice, Firefox וכל עורך שמשתמש ב-Enchant או ב-Hunspell יכולים לבדוק עברית. בשורת
הפקודה `hspell` עצמו מקבל קובץ ומפרט את מה שאינו מזהה, וזה שימושי בסקריפטים.

## LibreOffice

הפעילו פריסת טקסט מורכב תחת כלים, אפשרויות, הגדרות שפה, שפות: סמנו את תיבת CTL והגדירו עברית כשפת
ה-CTL. זה משחרר את כפתורי הפסקה מימין לשמאל בסרגל הכלים ומאפשר לכם להגדיר גופן CTL נפרד, וזה המקום
שאליו הולכת בחירת ה-Culmus שלכם. מסמכי Word משולחים דוברי עברית נפתחים אז עם הכיוון שלהם שלם.

הרגל אחד שראוי לרכוש: הגדירו את כיוון הפסקה במקום להילחם בסמן. פסקה מימין לשמאל מטפלת נכון בעצמה
במספרים ובמילים אנגליות משובצים; פסקה משמאל לימין שהוקלדה בה עברית לא.

## מה עדיין כואב

טקסט בכיוונים מעורבים בשמות קבצים ובפקודות מעטפת אינו נעים ואני בעיקר נמנע ממנו. יישומים מסוימים
עדיין מציגים עברית במשקל גופן שגוי או מתעלמים מגופן ה-CTL. והאלגוריתם הדו-כיווני שוגה בתווים
הנייטרליים, פיסוק וסוגריים, לעיתים קרובות מספיק כדי שתלמדו לבדוק.

שום דבר מזה אינו סיבה לא לעבוד בעברית בלינוקס. זו סיבה להשקיע את השעה בהגדרה נכונה, פעם אחת, במקום
להילחם בכל חלק כשאתם פוגשים אותו.
