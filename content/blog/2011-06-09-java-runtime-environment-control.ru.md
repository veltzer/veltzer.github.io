Есть четыре способа управлять средой Java во время выполнения:

- Переменная окружения _JAVA_OPTIONS.
- Командная строка при запуске виртуальной машины Java.
- Исходный код на Java. В этом случае нужно убедиться, что опция задана до того, как её подхватит подсистема, для которой она предназначена.
- В Java Web Start для управления средой, передаваемой исполняющей JVM, можно также использовать файл JNLP.

Примеры:

- `export _JAVA_OPTIONS='-Dawt.useSystemAAFontSettings=lcd'`
- `java -Dawt.useSystemAAFontSettings=lcd [arguments...]`
- `System.setProperty("awt.useSystemAAFontSettings","lcd");`
- `property name="awt.useSystemAAFontSettings" value="lcd"` (внутри элемента `resources`)

У каждого из этих способов, естественно, есть свои достоинства и недостатки. В Java Web Start переменными окружения или командной строкой управлять трудно, но два варианта (файл JNLP и сам исходный код) остаются в вашем распоряжении.

Некоторые свойства, например опция сглаживания, по умолчанию известны своей плохой настройкой, и если задать её (как показано выше), внешний вид и удобство работы заметно улучшатся.

Значения ключа `awt.useSystemAAFontSettings` таковы:

- `false` соответствует отключению сглаживания шрифтов на рабочем столе.

- `on` соответствует режиму Gnome «Лучшие формы / Лучший контраст» (аналога в настройках Windows нет).

- `gasp` соответствует стандартному («Standard») сглаживанию шрифтов Windows (аналога в настройках рабочего стола Gnome нет).

- `lcd` соответствует «субпиксельному сглаживанию» (`subpixel smoothing`) Gnome и ClearType в Windows.

Какой вариант лучше? Честно говоря, не знаю. На моём ноутбуке лучше всего выглядит `lcd`. Расскажите о своём опыте...
