הייתי צריך טבלת שמות טמפו תמציתית, מודרנית ונוחה לשימוש, ולא הצלחתי למצוא אחת טובה ברשת
(מה שהפתיע אותי — אולי אני לא כזה מוצלח בעניין הזה של גוגל...).
[הערך "Tempo" בוויקיפדיה](http://en.wikipedia.org/wiki/Tempo) מכיל המון מידע אבל חסר בהיבט הזה.
אז הנה טבלה לשימושי, ואני מקווה גם לשימושכם. הטבלה נגזרת ממטרונום מודרני סטנדרטי שאני משתמש בו
([Korg KDM-2](https://web.archive.org/web/20120411215852/http://www.korg.com/KDM2)).

| --- | --- |
| Largo | ‎(-)40-60 |
| Larghetto | 60-66 |
| Adagio | 66-76 |
| Andante | 76-108 |
| Moderato | 108-120 |
| Allegro | 120-168 |
| Presto | 168-200 |
| Prestissimo | ‎200-240(+) |
