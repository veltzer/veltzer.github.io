Этот сайт статический. Каждая страница – это файл, написанный заранее и
отдаваемый как есть сервисом GitHub Pages по адресу `veltzer.org`; пока вы
читаете, на сервере ничего не выполняется.

- **Генератор.** [rssite](https://github.com/veltzer/rssite) – генератор
  статических сайтов, который я написал на Rust, – превращает посты в Markdown
  и шаблоны Tera в страницы на всех трёх языках, а заодно строит ленты, карту
  сайта и поисковый индекс.
- **Сборка.** [rsconstruct](https://github.com/veltzer/rsconstruct), мой
  инструмент сборки, запускает rssite вместе с проверками: HTML проходит
  валидацию, JavaScript, CSS, Python и shell – линтеры, блог проверяется на
  орфографию на английском и иврите, а медиаданные сверяются с источниками.
  Он пересобирает только то, что изменилось, и GitHub Actions запускает его
  при каждом push.
- **Дизайн.** Цвета, шрифты и темы берутся из набора дизайн-токенов, общего
  с моими учебными сайтами.
- **Аналитика.** [GoatCounter](https://veltzer.goatcounter.com), который не
  ставит cookie; его панель открыта для всех.
- **Исходный код.** Всё, включая эту страницу, лежит в
  [veltzer/veltzer.github.io](https://github.com/veltzer/veltzer.github.io).

Подробности сборки ниже меняются с каждым коммитом. Они собраны на этой
странице, а не в подвале каждой страницы, чтобы коммит, меняющий один пост,
пересобирал и заново публиковал только этот пост, а все остальные страницы
оставались ровно такими, какими были.
